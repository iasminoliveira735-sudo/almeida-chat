# Almeida Chat

Chat em tempo real usando Node.js, Express e WebSocket.

## GitHub
Envie TODOS os arquivos desta pasta para um repositório. A pasta `public` já está pronta.

## Render
Crie um **Web Service** ligado ao repositório.
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: Node

O servidor usa automaticamente a porta fornecida pelo Render. Abra a URL HTTPS do Render e o WebSocket usa WSS automaticamente.

## Observação
Esta é uma base funcional de mensageiro em tempo real. Um app no nível completo do WhatsApp exige autenticação, banco de dados, mídia, notificações push, chamadas, criptografia ponta a ponta e outros serviços.
